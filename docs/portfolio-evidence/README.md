# Portfolio evidence

This folder demonstrates the implemented flow with synthetic data only.

1. `sanitized-sample-input.json` is the exact known-part request used in the CLI demonstration.
2. `01-sanitized-input.png` presents the same capture in a readable portfolio view.
3. `02-processing-flow.png` shows the actual implemented processing stages and evidence boundary.
4. `sanitized-sample-output.json` is a verified summary of the result produced by the deterministic pipeline.
5. `03-verified-output.png` summarizes the matched result and rows produced.

The workbook screenshots show the empty database template rather than live operational data:

- `workbook-readme.png`
- `workbook-capture-inbox.png`
- `workbook-review-queue.png`

All identifiers are fictional. No Telegram tokens, Google credentials, customer messages, supplier contacts, live file links, or production workflow exports are included.
